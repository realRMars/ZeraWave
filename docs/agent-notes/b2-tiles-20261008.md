## Ownership, accounting and shutdown

`ownership-before.md` records the required pre-repair state table. Current rules:

| State / owner | Protection and release event |
|---|---|
| Private gesture / unknown command | Preview is not acceptance; uncertain outcomes retain producers until ordered reconciliation. Known rejected work is not replayed. |
| Current scene + retained Undo/Redo/structural history | Immutable versions remain; history expiry/new-edit Redo invalidation releases only obsolete references. Current pixels do not disappear to satisfy a count. |
| PNG job / active token | Worker owns its admitted lease until Future completion/cancellation. Live reservations cannot be reconciled or deleted. |
| Failed resource / Retry | Current/history/save/render obligation retains accepted pixels. Failure/retry bookkeeping alone cannot pin an expired revision forever. |
| Save/recovery pin | Exact frozen requested revision survives until success, actual cancellation or explicit Discard. Four checkpoint bound remains. |
| Output publication / renderer reader | ACK/supersession/context retirement or renderer stop releases pins; storage/leases outlive active readers. |
| Internal metadata | Last current/history/job/save/publication reference releases obsolete internal row; late registry callbacks cannot revive it. Public Library records remain explicit assets. |
| Working PNG | Indexed provenance plus no legitimate reference permits retirement; durable intent precedes unlink. Failed deletions retry boundedly, including normal reopen. |
| Originals / Library / dependencies / legacy / evidence | Protected. Interrupted active files are retained conservatively; filename resemblance never proves disposable ownership. |

## Research and design decision

Original indexed/reference-managed PNG storage is the smallest increment supported
by the demonstrated plateau. No GIMP/GEGL/MyPaint code or engine was adopted.
[GIMP undo design](https://developer.gimp.org/core/specifications/undo/) (updated
2025-11-17; CC-BY-SA 4.0 documentation) separates history/saved state and redo
branch lifetime. [GIMP configuration](https://www.gimp.org/man/gimprc.html)
separates Undo memory, tile-cache and swap space. [GEGL release notes](https://gegl.org/release-notes.html)
(0.4.62, 2025-10-04) motivate distinguishing swap exhaustion from history limits;
[MyPaint canvas backend](https://www.mypaint.app/en/docs/backend/canvas/)
(2024-03-12, documentation commit 1de62a4, CC-BY 4.0) illustrates sparse painted-tile
storage and local update ownership. These are architecture comparisons, not a claim
of verified/copied engine source revisions/licenses. Inaccessible GitLab/raw-source
references were not relied upon for code reuse. Native resolution/quality and the
single document authority remain intact; full-image PNG persistence is retained.
