# Retired root helpers — 2026-09-28

This directory preserves byte-for-byte copies of obsolete root-level helper
scripts removed from the active project root during the 2026-09-28 cleanup.
They are historical artifacts and are unsupported against current ZeraWave
source. They must not be executed as part of current development; in particular,
`apply_3b.py` is a historical patch script.

The supported live and shader entry points remain under `app/visuals/`.
