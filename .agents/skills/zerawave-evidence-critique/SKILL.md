# ZeraWave evidence critique

Read the current review assignment, [working agreement](../../../AGENTS.md) and
relevant [visual direction](../../../ZERAWAVE_VISUAL_IDENTITY.md).
[ROADMAP](../../../ROADMAP.md) remains the sole plan; this review is evidence,
not an acceptance decision or new backlog.

## Review the correct candidate

1. Start with the designated pack index and manifest, following an explicitly
   identified final delta. Bind candidate and baseline hashes, scoped diff,
   artifact hashes, timestamps, input, session/settings and evidence class before
   judging. Verify identity against accessible source when the assignment concerns
   the current checkout. Otherwise label it a snapshot review. Do not relabel old
   captures as final; accept reused evidence only with unchanged relevant source
   or a documented equivalence argument. Explain what that argument covers.
2. Inspect representative normal-speed motion and the affected held, entry,
   transition, return or release cases already supplied. Describe visible behavior
   at named artifact times: composition, identity/craft, sustained versus event
   response, quiet/active/release range, continuity and developing variety. A still
   or extracted frame sequence supports narrower observations than played motion;
   state playback limitations. Follow current acceptance criteria without inventing
   a score threshold or assuming depth/3D is compulsory.
3. Separate technical findings, artistic judgments and confidence. Passing tests
   do not establish compelling art. Synthetic input demonstrates controlled
   response; decoded silent replay can show correspondence to measured features,
   but not continuous music listening. Claim listening only when actually performed
   with the identified audio/visual conditions. Do not infer lyric/genre recognition
   or extended-session quality from short evidence.
4. Attribute consequential observations to supported components: world geometry,
   material, palette, camera, spatial effect, director or transition. Use
   [technique ownership](../../../TECHNIQUE_LIBRARY.md), available isolation or
   matched evidence and affected source relationships. Distinguish an observed
   symptom from a suspected cause; a composite image alone may not identify the
   responsible component. Preserve unaffected components and intentional changes
   under [maintenance contracts](../../../docs/MAINTENANCE_CONTRACTS.md).
5. Return a finite set of consequential findings, with artifact/time, criterion,
   supported attribution, confidence, impact and a high-value correction or next
   discriminating check. State strengths and remaining evidence limits. If scoring
   is requested, explain its basis and provisional scope; scores are not user
   acceptance, full AV validation or permission to integrate.

## Finish

Stop after the assigned critique. If source or pack identity is unresolved,
report the mismatch and restrict conclusions to verified artifacts; request only
the missing binding needed to continue. Do not silently substitute another pack,
start an automatic fix/review loop, dispatch workers, run broad recapture or
control unrelated previews. Additional evidence collection requires assignment
scope and should resolve a specific uncertainty using existing
[Studio procedures](../../../DEVELOPMENT_STUDIO.md).
